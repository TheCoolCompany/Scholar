# Scholar
This is a Google Scholar Bot. It contains the following scripts: 

* Google Scholar.py gives the amount of articles uploaded in a certain time span and plots them on a chart. 
* runScholarSearchAll.py is based on Google Scholar.py and writes the amount of articles relevant for wind tubine and farm control into text files.

There are two subfolders

* The folder output contains the output of runScholarSearchAll.py.
* The folder MATLABscripts4plots contains MATLAB scripts to visualize the text files in the output folder.
